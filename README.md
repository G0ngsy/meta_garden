# 느긋한 공동 정원

React + Vite + TypeScript + React Three Fiber/Drei로 만드는 웹 공동 정원.

## 실행

Node.js 20.19+ 또는 22.12+ 환경에서 저장소 루트 기준:

```sh
npm install
npm run dev
```

표시된 로컬 주소로 접속합니다. `npm run build`로 TypeScript 검사와 배포 빌드를 실행합니다.

## 구조

- `frontend/`: 3D 화면과 사용자 인터페이스
- `backend/`: 향후 FastAPI WebSocket 서버
- `docs/`: 개발 순서와 기능 명세

현재 한국 전통 정원에서 혼자 걷는 첫 플레이 버전입니다. 연못과 돌다리, 기와 정자, 소나무, 대나무, 돌담, 평상, 꽃밭을 배치했습니다.

- WASD 또는 방향키: 정원 좌표 기준 이동 및 캐릭터 회전
- C 또는 화면 버튼: 쿼터뷰/3인칭 전환
- 접속마다 랜덤 닉네임과 한복 느낌의 캐릭터 색상 생성
- 연못은 중앙 돌다리로 통과하며 나무, 정자 기둥, 평상 및 맵 경계에서 이동 제한

3인칭은 캐릭터 뒤를 따라가는 카메라이며, 별도 마우스 회전은 없습니다. 멀티플레이, 실제 날씨/KST 연동, 정원 활동과 모바일 터치 조작은 향후 구현합니다.
