# 느긋한 공동 정원

React + Vite + TypeScript + React Three Fiber/Drei로 만드는 웹 공동 정원.

## 실행

Node.js 20.19+ 또는 22.12+ 환경에서 저장소 루트 기준:

```sh
npm install
npm run dev
```

표시된 로컬 주소로 접속합니다. `npm run build`로 TypeScript 검사와 배포 빌드를 실행합니다.

## 구조

- `frontend/`: 3D 화면과 사용자 인터페이스
- `backend/`: 향후 FastAPI WebSocket 서버
- `docs/`: 개발 순서와 기능 명세

현재 전체 화면 3인칭으로 한국 전통 정원을 산책하는 로컬 플레이 버전입니다. 넓은 돌마당, 곡선 기와 정자, 연못과 아치형 돌다리, 나무, 대나무, 잔디와 꽃을 배치했습니다. 승인된 콘셉트 구도를 실제 3D 공간으로 옮긴 첫 개선 버전이며 세부 건축·식생 품질은 콘셉트 이미지와 차이가 있습니다.

- WASD 또는 방향키: 카메라 방향 기준 이동 및 캐릭터 회전
- 마우스/터치 드래그: 주변 둘러보기. 마우스 휠: 카메라 거리 조절
- C 또는 화면 버튼: 쿼터뷰/3인칭 전환
- 첫 방문에 랜덤 닉네임과 한복 느낌의 캐릭터 색상 생성, 이후 브라우저에 유지
- 연못은 돌다리로 통과하며 나무, 정자 기둥, 난간 및 맵 경계에서 이동 제한

3인칭으로 시작하며 걷는 동안 팔·다리가 움직입니다. 계단과 돌다리는 지형 높이를 따라 이동합니다. 조작 안내는 화면 아래 버튼으로 열 수 있습니다. 멀티플레이, 실제 날씨/KST 연동, 정원 활동은 향후 구현합니다. 모바일 터치 이동과 드래그 시점을 지원하지만 실제 기기별 성능 검증은 남아 있습니다.

## PWA와 오프라인 산책

프로덕션 빌드에서는 앱 설치 정보와 정적 자산 캐시를 제공합니다. 첫 접속 후 **오프라인 산책 준비 완료**가 표시되면 서버가 꺼져도 저장된 정원에서 혼자 걸을 수 있습니다. 휴대폰에서는 화면 방향 버튼을 누르는 동안 이동합니다. 닉네임과 캐릭터 색상은 브라우저에 저장합니다.

`npm run build` 후 `npm run preview`에서 확인하세요. `npm run dev`에서는 서비스 워커를 등록하지 않습니다. HTTPS 배포 및 설치 방법, 저장 한계와 업데이트 흐름은 [PWA 안내](docs/pwa.md)를 참고하세요. 현재 외부 배포는 하지 않았습니다.

`npm test`는 설치된 Edge를 사용해 서버 종료 후 재접속, 터치 이동, 업데이트, 캐시 실패와 재시도를 검사합니다. 먼저 빌드를 실행해야 합니다.
