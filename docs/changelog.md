# 작업 기록

## 2026-11-05 — 설치형 PWA와 오프라인 산책

- 사용자가 승인한 정자·새싹 아이콘 제작, 192/512px 앱 아이콘과 180px Apple 아이콘 추가.
- 앱 이름, 언어, 독립 창 실행, 시작 경로를 manifest에 지정.
- 프로덕션 빌드 시 정적 자산 목록과 콘텐츠 해시 기반 서비스 워커 생성. API와 외부 요청은 캐시하지 않음.
- 모든 필수 파일의 캐시를 확인한 뒤에만 준비 완료 표시. 인터넷 연결 감지, 저장 실패와 재시도 안내 추가.
- 설치가 가능한 브라우저에서는 설치 요청, 그 외에는 iPhone/Android/PC 설치 방법 안내. 취소 후에도 산책 가능.
- 업데이트 대기 및 사용자 선택 후 적용. 현재 캐시는 새 버전 활성화 때 정리.
- 닉네임/캐릭터 색상 로컬 저장. 모바일 터치 방향 버튼, 포커스 이탈 및 포인터 취소 시 이동 해제.
- 3인칭 카메라가 지붕 등 지형에 가려질 때 카메라 높이를 올려 캐릭터를 가리지 않도록 보완.
- 검증: TypeScript 및 프로덕션 빌드 통과. 실제 Edge 자동 검사 통과: 서버 종료·오프라인 재실행, 터치 이동, 업데이트, 저장 실패·재시도 복구.
- 남은 확인: 실제 기기 홈 화면 설치, iPhone/Android 그래픽 성능. 기존 번들 크기 경고는 남음.

## 2026-11-05 — 한국 전통 정원 첫 플레이 버전

- 사용자가 승인한 한국 전통 분위기로 환경 변경.
- 연못, 돌다리, 기와 정자, 소나무, 대나무, 꽃밭, 돌담, 대문, 평상 추가.
- 랜덤 닉네임과 한복 느낌의 캐릭터 색상 생성.
- WASD/방향키 이동, 이동 방향 회전, 연못·나무·정자 기둥·평상·맵 경계 충돌 처리.
- 쿼터뷰/캐릭터 추적 3인칭 전환(C 키 및 화면 버튼), 창 포커스 상실 시 키 상태 초기화.
- 이미지 생성 도구로 예상 콘셉트 이미지 제작. 실제 화면과 구분되는 분위기 참고용 이미지이며 런타임 자산으로 사용하지 않음.
- 검증: TypeScript 검사와 프로덕션 빌드 통과. 번들 크기 경고는 기존과 동일하게 남음.
- 개발 서버 시작 확인. 앱 내 브라우저에서 localhost 연결 시간 초과로 시각 및 실제 이동 검증은 미완료.
- 후속 확인: 브라우저에서 이동·다리 통과·충돌·시점 전환, 3인칭 건물 가림과 카메라 조작감.
