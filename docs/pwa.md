# 설치 및 오프라인 사용자 흐름

## 첫 방문

1. HTTPS로 배포된 정원 주소를 연다. 개발 검증은 localhost에서도 가능하다.
2. 설치 없이 바로 산책한다. PC는 WASD/방향키, 휴대폰은 방향 버튼을 누르는 동안 이동한다.
3. 화면에 '오프라인 산책 준비 완료'가 표시될 때까지 연결을 유지한다. 모든 정적 파일의 캐시가 확인된 뒤에만 완료를 표시한다.
4. 원하면 '정원 설치하기'를 누른다. 설치 이벤트가 없는 브라우저에서는 '설치 방법' 안내를 제공한다. 브라우저 지원과 기기별로 설치 메뉴가 다를 수 있다.
5. 설치 창을 취소하거나 안내를 닫아도 산책을 계속한다. 설치 여부와 오프라인 준비 완료는 별개다.

## 다시 방문

- 준비 완료 후에는 인터넷이나 호스팅 서버가 끊겨도 저장된 정적 파일로 실행된다.
- 닉네임과 캐릭터 색상은 이 브라우저의 로컬 저장소에 보관한다. 위치는 재실행 시 입구로 돌아간다.
- 브라우저의 연결 감지 상태가 오프라인이면 '오프라인 산책 중'으로 표시한다. 인터넷 연결 감지는 서버의 정상 동작을 보장하지 않는다.
- 브라우저 데이터 삭제, 저장 공간 정리/회수, 다른 브라우저나 새 기기로 이동하면 온라인에서 다시 준비해야 한다.
- 최초 접속부터 서버에 연결할 수 없는 경우에는 실행할 수 없다.

## 저장 실패와 업데이트

- 캐시 설치가 실패하면 완료로 표시하지 않고 다시 준비하기 버튼을 제공한다.
- 새 버전은 대기하며 사용자가 '지금 업데이트'를 선택할 때 적용한다. 적용 후 열린 같은 정원의 창들이 다시 로드될 수 있다.
- 새 버전 전체가 저장되기 전에는 기존 버전을 제거하지 않는다. 활성화 시 이 앱의 이전 캐시만 정리한다.
- 업데이트 버튼을 누르지 않으면 현재 산책을 계속한다. 모든 기존 앱 창을 닫은 뒤 다시 열 때는 대기 중이던 버전이 적용될 수 있다.

## 현재 범위

- 오프라인: 정원 렌더링, 이동, 충돌, 카메라 전환.
- 아직 미구현: 멀티플레이, 날씨/KST, 정원 활동, 작업 동기화. 연결 복구 시 자동으로 멀티플레이가 시작되는 기능은 없다.
- API나 임의의 외부 요청은 서비스 워커 캐시에 저장하지 않는다.
- 외부 폰트나 CDN 모델에 의존하지 않는다.

## 실행 및 배포

```sh
npm ci
npm run build
npm run preview
```

출력된 preview 주소에서 확인한다. `npm run dev`에서는 오래된 파일 캐시가 개발을 방해하지 않도록 서비스 워커를 등록하지 않는다.

`frontend/dist`를 HTTPS 정적 호스팅의 도메인 루트(`/`)에 배포한다. 현재 하위 경로 배포는 지원하지 않는다. `sw.js`, `index.html`, `manifest.webmanifest`에는 `Cache-Control: no-cache`를 권장하며 해시가 붙은 assets는 장기 캐시할 수 있다. 새 파일 업로드가 완료되기 전에 이전 해시 자산을 삭제하지 않는 원자적 배포를 권장한다.

## 검증

`npm test`는 빌드 결과를 실제 headless Edge에서 검사한다. 먼저 `npm run build`를 실행한다. 로컬 Edge가 설치되어 있어야 한다.

- 최초 저장 완료, 설치 방법 열기/닫기, 카메라 전환, 터치 이동 렌더링 변화.
- 브라우저 오프라인 재로드 및 정적 서버 종료 후 재로드.
- 방문자 정보 유지, 새 서비스 워커 대기와 사용자 선택 후 활성화.
- 필수 아이콘 다운로드 실패 시 준비 실패 표시 및 재시도 복구.

OS 홈 화면 설치 자체와 실제 iPhone/Android 기기 성능은 별도 기기 검증이 필요하다.
