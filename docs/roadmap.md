# 개발 순서

1. 한국 전통 정원: 승인된 3인칭 구도에 맞춘 넓은 돌마당, 곡선 기와 정자, 연못과 돌다리, 나무와 꽃. 전체 화면 개선 및 Edge 화면 확인 완료. 이후 모델·식생·조명 품질을 더 개선할 수 있음.
2. 로컬 플레이: 방문자 유지, 카메라 기준 WASD 이동, 걷기 동작, 지형 높이/충돌, 드래그 시점과 휠 거리, 쿼터뷰 전환. 키보드·모바일 크기 터치·드래그 검사 완료.
3. 실시간 멀티플레이: FastAPI WebSocket, 방 입장/퇴장, 위치 동기화와 보간, 서버 이동 검증.
4. 서울 실제 날씨 및 KST: 서버 날씨 조회와 캐시, 낮/밤 조명, 비/눈 효과, 조회 실패 시 마지막 상태와 갱신 시각 표시.
5. 정원 활동: 물주기, 잡초뽑기, 약주기, 상호작용 거리와 도구 표시.
6. 공동 관리: 정원 상태 영속 저장, 동시 작업 처리, 성장과 관리 기록.
7. 모바일: 터치 이동·드래그와 반응형 UI 구현. 실제 iPhone/Android 설치 및 기기 성능별 그래픽 조정은 남음.

각 단계마다 실제 브라우저에서 동작을 확인한 뒤 다음 단계로 진행합니다.
