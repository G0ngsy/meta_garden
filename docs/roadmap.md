# 개발 순서

1. 한국 전통 로우폴리 정원: 연못, 돌다리, 기와 정자, 디딤돌, 소나무, 대나무, 평상, 돌담과 꽃밭. 첫 구현 완료, 브라우저 시각 검증 필요.
2. 로컬 플레이: 랜덤 닉네임/캐릭터, WASD 및 방향키 이동, 장애물 충돌, 쿼터뷰/3인칭 전환(C 키와 버튼). 첫 구현 완료, 실제 조작 검증 필요.
3. 실시간 멀티플레이: FastAPI WebSocket, 방 입장/퇴장, 위치 동기화와 보간, 서버 이동 검증.
4. 서울 실제 날씨 및 KST: 서버 날씨 조회와 캐시, 낮/밤 조명, 비/눈 효과, 조회 실패 시 마지막 상태와 갱신 시각 표시.
5. 정원 활동: 물주기, 잡초뽑기, 약주기, 상호작용 거리와 도구 표시.
6. 공동 관리: 정원 상태 영속 저장, 동시 작업 처리, 성장과 관리 기록.
7. 모바일: 터치 이동과 카메라 조작, 반응형 UI, 기기 성능별 그래픽 조정.

각 단계마다 실제 브라우저에서 동작을 확인한 뒤 다음 단계로 진행합니다.
